# Claude Development Server Rules

## Worktree Port Allocation (3000–3009)

Each git worktree gets a dedicated **port pair**: even port for HTTP, odd port (even + 1) for HTTPS.

| Slot | Use Case | HTTP | HTTPS | Command Example |
|------|----------|------|-------|-----------------|
| 0 | main worktree | 3000 | 3001 | `npm run dev` |
| 1 | worktree 1 | 3002 | 3003 | `$env:PORT = "3002" ; npm run dev` |
| 2 | worktree 2 | 3004 | 3005 | `$env:PORT = "3004" ; npm run dev` |
| 3 | worktree 3 | 3006 | 3007 | `$env:PORT = "3006" ; npm run dev` |
| 4 | worktree 4 | 3008 | 3009 | `$env:PORT = "3008" ; npm run dev` |

> **Note**: When `VITE_HTTPS=true`, the HTTP proxy listens on the base port (e.g., 3002) and Vite serves HTTPS on port + 1 (e.g., 3003). This is handled automatically by vite.config.mjs.

### Rule: Assign Ports Based on Worktree Slot

- The **main** worktree always uses port **3000** (the default)
- Additional worktrees use the next available even port: 3002, 3004, 3006, 3008
- Never use an odd port directly — odd ports are reserved for the HTTPS companion server
- Set the port via the `PORT` environment variable: `$env:PORT = "3002" ; npm run dev`

### Rule: Check for Existing Servers First

Before running any dev server command:
1. Check if the worktree's assigned port is already in use
2. If it is, identify what's running on it
3. If it's the same project, use that existing server
4. If it's a different process, kill it first

### Rule: When a Port is Occupied

If a port is occupied by a different process:
1. Identify the process: `netstat -ano | findstr :<port>` (Windows) or `lsof -ti:<port>` (macOS/Linux)
2. Kill the process if it's not critical: `taskkill /PID <PID> /F`
3. Only then start your dev server

### Rule: Port Configuration

**For personal setup (recommended):**
Create a `.env.local` file (ignored by git) with:
```
STRICT_PORT=true
```

This will make your local vite config use `strictPort: true` while allowing other developers to use the default behavior (port with fallback to other ports if occupied).

### Rule: Enable Agents to Start Dev Servers

When an agent is working on changes that need user validation:
1. Determine which worktree slot to use based on the working directory
2. Start the dev server on the assigned port: `$env:PORT = "<port>" ; npm run dev`
3. Inform the user of the URL: `http://localhost:<port>/`
4. For HTTPS (if needed): `$env:PORT = "<port>" ; $env:VITE_HTTPS = "true" ; npm run dev`

### Consequences
- Using unassigned ports wastes the 3000–3009 range and causes confusion
- Always use even ports (3000, 3002, 3004, 3006, 3008) for the base server
- Always check before starting a new server
