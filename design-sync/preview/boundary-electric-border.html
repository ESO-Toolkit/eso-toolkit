Mechanics. @property --tdps-angle (syntax <angle>, initial 0deg, inherits false) lets the conic-gradient's start angle interpolate; without it the ring is a graceful static fallback. The host card must set overflow: visible (PlayerCard.tsx:605) plus the amber 1px border, or MUI Card's default clipping cuts off the negative-inset ring and halo. The conic gradient is mode-independent; only host border/shadow and halo change per mode. Both layers animate via CSS keyframes so the global prefers-reduced-motion rule neutralises them automatically.
