Background Layers — Nebula (dark) / Aurora (light)

The site-wide 4-layer atmospheric background: base gradient wash → drifting clouds → floating particles → grid overlay. One fixed, pointer-events:none stack at zIndex:-1. Sources: nebula-background-technique.md, src/features/loadout-manager/components/NebulaBackground.tsx, AuroraBackground.tsx, src/components/shared/SiteBackground.tsx

Doc vs implementation: the root technique doc (nebula-background-technique.md) describes 45–60 particles and clouds with filter: blur(60–80px). The production components deliberately ship pre-diffused radial gradients with no filter:blur and 20–25 particles max, "tuned to avoid iOS Safari GPU crashes" (NebulaBackground.tsx:6-7). The values in this card are the as-built component values. Both components also zero all animation under prefers-reduced-motion: reduce (NebulaBackground.tsx:70-75).
