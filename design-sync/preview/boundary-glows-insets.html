Rule (B10): accent glow is always 0 0 <R>px rgba(accent, 0.12–0.35) appended after the black depth shadow, never alone — R grows with surface size (14px pills → 18–28px cards → 60px page-level hover). Light mode either shrinks alpha or drops the glow.
Rule (B11): the top inner highlight inset 0 1px 0 rgba(255,255,255,α) follows a strict alpha scale — 0.05–0.06 panels/cards · 0.08–0.12 menus/hover · 0.2–0.3 glossy chips (the only tier that also adds bottom shading inset 0 -1px 0 rgba(0,0,0,0.1–0.2)) · 0.6–0.9 light mode. Recessed inputs invert the scheme entirely: inset 0 2px 4px rgba(0,0,0,0.4) dark / 0.06 light.
