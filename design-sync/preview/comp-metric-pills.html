Palette divergence — document both, do not unify

MetricPill's intent palette (MetricPill.tsx:27-53) is a divergent copy of the glossy-chip variant palette (src/utils/playerCardStyleUtils.ts:95-155). Identical: success ≡ chip green, info ≡ chip lightBlue, danger gradient/border ≡ chip championRed (both text #ff6666). Diverged: warning shares the gold gradient/border but uses text #ff9800 where the chip gold uses #ffd54f; neutral is slate rgba(148,163,184,…) where the chip silver is rgba(236,240,241,…) with text #ecf0f1; light-mode text is forced #000000 here vs #1f2937 on chips (playerCardStyleUtils.ts:44). Pills are also flat (radius 10, no gloss); chips are the G4 glossy recipe (radius 28, shine sweep, gloss dome). Different surfaces — transcribe each as-is.

Other exact values: hover translateY(-1px) with transition: transform 120ms ease, box-shadow 120ms ease (:115-118); dark container shadow none (:111-114); label textShadow dark 0 1px 2px rgba(0,0,0,0.5) / light 0 1px 1px rgba(15,23,42,0.1) (:133-136); value textShadow dark 0 1px 3px rgba(0,0,0,0.6) / light 0 1px 2px rgba(15,23,42,0.15) (:146-149).
