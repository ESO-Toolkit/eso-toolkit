## Longer version (for a forum / long-form channel)

**Introducing ESO Toolkit and Kalpa — community tools for ESO**

Hey all,

I've been working on two free, open-source tools for the Elder Scrolls Online community
and Kindra was kind enough to offer space in #announcements. Quick rundown below — happy
to answer questions after it goes up.

### 🧪 ESO Toolkit — web-based combat log analyzer

For digging into trial and dungeon logs — whether you're progging a hard mode, debugging
a tricky mechanic, or just wondering why your parse dipped on the last pull.

- 🎬 **Fight Replay** — 3D playback of the encounter. Scrub the timeline, rotate the
  camera, watch positioning, mechanics, and cooldowns play out at 60fps.
- 📊 **Parse Analysis** — DPS/HPS, ability breakdowns, uptime tracking, player-vs-player
  comparisons.
- 🛡️ **Loadout Manager** — gear sets, skill bars, and champion points per player.
- ✍️ **Scribing Support** — detects signature scripts across every event type
  (including resource events).
- 🧭 **Role Detection** — tanks, healers, and DDs classified automatically from actual
  combat behavior, not just class.
- 👥 **Roster Hub** — manage your trial/dungeon rosters in one place.

**Live site:** https://esotk.com/
**Source / issues:** https://github.com/ESO-Toolkit/eso-toolkit

### ⚙️ Kalpa — desktop addon manager *(alpha)*

A fast, open-source addon manager for ESO. Built with **Rust and Tauri** for native
performance — just **15 MB**, no Java runtime required.

- ⚡ **One-click installs** and updates
- 🧩 **Dependency resolution** — automatically handles required libraries
- 🎭 **Addon profiles** — switch loadouts per character or role
- 📦 **Pack Hub** — share and discover addon collections
- 💾 **SavedVariables backup** — never lose your addon settings again
- 🔁 **Minion migration** — one-click import from your old manager

**Source / downloads:** https://github.com/ESO-Toolkit/kalpa

Kalpa is still in **alpha**, so early-adopter feedback is especially valuable — bug
reports, missing features, rough edges, all very welcome.
