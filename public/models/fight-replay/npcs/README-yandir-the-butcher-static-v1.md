# Yandir the Butcher static replay model

This GLB is a project-authorized fan-project reconstruction made from screenshots, not geometry
extracted from the ESO client. It is used by the fight replay's detailed-figures renderer with the
existing capsule as its loading, error, and low-performance fallback.

- Reference page: <https://esomodelviewer.com/characters/post/82-yandir-the-butcher>
- Encounter: Yandir the Butcher, Kyne's Aegis trial
- Inputs: front, left, back, and right reference views
- Geometry: Tencent Hunyuan3D-2mv multiview reconstruction
- Texture: multiview projection atlas
- Runtime asset: one mesh, one material, 45,000 triangles, 1,940,204 bytes
- Visual QA: front, side, back, and three-quarter renders reviewed on 2026-09-04

owners, including ZeniMax Media/Bethesda Softworks. Do not reuse this asset outside this project's
authorized fan prototype without a separate rights review.
